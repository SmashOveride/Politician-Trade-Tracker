# Android (Lite) build

Wraps the same Flask backend (`../backend/`) and frontend (`../frontend/`)
the desktop builds use, embedding a real Python interpreter via
[Chaquopy](https://chaquo.com/chaquopy/) and displaying the frontend in a
WebView. Only the "Lite" data path applies here (snapshot download, no live
PDF/OCR pipeline) -- see the root `README.md`'s "Android build & signing"
section for the full picture, including release signing and install
instructions.

## No Gradle wrapper is checked in

This project deliberately has no `gradlew`/`gradlew.bat`/`gradle-wrapper.jar`
-- those are binary/generated files, and CI (`.github/workflows/build-android.yml`)
uses [`gradle/actions/setup-gradle`](https://github.com/gradle/actions) to
provision Gradle 8.10 directly instead. To build locally:

- **With Android Studio** (recommended once you have it installed): open
  this `android/` folder as a project -- Android Studio detects the missing
  wrapper and offers to generate one automatically.
- **From the command line**: install Gradle 8.10+ yourself, then run
  `gradle wrapper --gradle-version 8.10` once from this directory to
  generate `gradlew`/`gradlew.bat` locally (these will remain untracked --
  see `.gitignore` -- so this is a one-time local step, not something to
  commit).

## `backend/`/`frontend/` are not duplicated here

`app/src/main/python/` is generated by the `syncPythonSources` Gradle task
(see `app/build.gradle.kts`) from the real `../backend`/`../frontend`
directories on every build, minus the live PDF/OCR pipeline files (mirroring
`packaging/macos_lite.spec`'s excludes). It's gitignored -- don't edit
anything under it directly, since a rebuild will overwrite it.
