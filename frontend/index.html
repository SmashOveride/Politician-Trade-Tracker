Data Source Settings

By default, the politician directory (name, party, state, photo) comes from the free congress-legislators community project — no signup required. Optionally, paste a free API key from api.data.gov below to source that same directory from the official Congress.gov API instead. If the key is missing or a request fails, the app automatically falls back to the free source. This setting does not change where trade disclosure data comes from.

All downloaded data is cached on this machine (in the data/ folder next to the app) so it's available instantly next time you open it — nothing is re-downloaded unless the source has actually changed. The app can also check for new disclosures automatically in the background, in addition to the manual "Refresh Data" button.
